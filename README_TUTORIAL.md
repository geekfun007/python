## 核心设计原则

### 1. 装饰器 (Decorators)

装饰器是Python中最强大的特性之一，用于在不修改原函数代码的情况下增强函数功能。

**核心概念：**
- 装饰器本质是一个接受函数作为参数并返回新函数的高阶函数
- 支持带参数的装饰器
- 可以叠加多个装饰器
- 使用 `functools.wraps` 保留原函数元信息

**参考文件：** `01_decorators_advanced.py`

### 2. 元类 (Metaclasses)

元类是"类的类"，控制类的创建过程。

**核心概念：**
- `type` 是所有类的元类
- 通过 `__new__` 和 `__init__` 控制类的创建
- 实现单例模式、ORM映射等高级功能
- 使用场景：框架设计、API设计

**参考文件：** `02_metaclasses.py`

### 3. 描述符 (Descriptors)

描述符协议允许自定义属性访问行为。

**核心概念：**
- 实现 `__get__`, `__set__`, `__delete__` 方法
- 数据描述符 vs 非数据描述符
- property、staticmethod、classmethod 都是描述符
- 用途：属性验证、延迟计算、类型检查

**参考文件：** `03_descriptors.py`

### 4. 上下文管理器 (Context Managers)

管理资源的获取和释放。

**核心概念：**
- 实现 `__enter__` 和 `__exit__` 方法
- 使用 `contextlib` 简化创建
- 异常处理和资源清理
- 支持异步上下文管理器

**参考文件：** `04_context_managers.py`

### 5. 生成器与迭代器 (Generators & Iterators)

惰性求值和内存高效的数据处理。

**核心概念：**
- `yield` 语句创建生成器
- 迭代器协议：`__iter__` 和 `__next__`
- 生成器表达式
- `yield from` 委托生成器

**参考文件：** `05_generators_iterators.py`

## 高级语法特性

### 1. 协程与异步编程 (Async/Await)

**核心特性：**

**核心特性：**
- 使用 `typing` 模块

- Protocol 协议类型
- TypeVar 和泛型函数

**参考文件：** `07_type_hints.py`

**参考文件：** `08_magic_methods.py`

## 重要注意事项

### 1. 内存管理

⚠️ **关键点：**
- Python 使用引用计数 + 垃圾回收
- 避免循环引用导致的内存泄漏
- 使用 `__slots__` 减少内存占用
- 及时关闭文件、数据库连接等资源
- 大数据处理使用生成器而非列表

### 2. 线程安全

⚠️ **关键点：**
- GIL (全局解释器锁) 限制
- 使用 `threading.Lock` 保护共享资源
- `queue.Queue` 是线程安全的
- 考虑使用 `multiprocessing` 代替 `threading`
- 不可变对象是线程安全的

### 3. 性能陷阱

⚠️ **避免：**
- 频繁的字符串拼接（使用 `join`）
- 全局变量访问（使用局部变量）
- 在循环中重复导入模块
- 过度使用异常处理控制流程
- 不必要的深拷贝

### 4. 异常处理

⚠️ **最佳实践：**
- 捕获具体异常而非 `Exception`
- 使用 `finally` 确保资源释放
- 自定义异常类继承合适的基类
- 不要忽略异常（避免空 `except`）
- 使用上下文管理器自动处理异常

### 5. 代码组织

⚠️ **注意：**
- 遵循 PEP 8 代码规范
- 使用虚拟环境隔离依赖
- 编写单元测试
- 文档字符串（docstrings）
- 类型提示提高代码可读性

## 性能优化

### 1. 选择合适的数据结构

```python
# 快速查找：使用 set 或 dict
# 有序数据：使用 list
# 固定数据：使用 tuple
# 计数：使用 collections.Counter
# 队列：使用 collections.deque
```

### 2. 使用内置函数和标准库

内置函数（如 `map`, `filter`, `sum`）通常比纯 Python 循环快。

### 3. 惰性求值

使用生成器和迭代器处理大数据集。

### 4. 缓存计算结果

使用 `functools.lru_cache` 缓存函数结果。

### 5. 并发和并行

- I/O 密集型：使用 `asyncio`
- CPU 密集型：使用 `multiprocessing`
- 混合型：使用 `concurrent.futures`
