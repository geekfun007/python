# Python 详解与实战教程

这是一个全面的 Python 学习项目，涵盖从基础到高级的各个方面，包含详细解释和实战代码示例。

## 📚 目录结构

### 1. 基础语法
- `01_syntax.py` - Python 基础语法详解

### 2. 数据类型与方法
- `02_basic_types.py` - 基本数据类型：int, float, bool
- `03_collections.py` - 集合类型：tuple, list, set, dict
- `04_classes.py` - 类与面向对象编程
- `05_enum_types.py` - 枚举类型
- `06_datetime.py` - 日期时间处理
- `07_regexp.py` - 正则表达式
- `08_error_handling.py` - 异常处理
- `09_iterators_comprehensions.py` - 迭代器与推导式

### 3. 逻辑与函数
- `10_logic_functions.py` - 逻辑控制与函数详解

### 4. 并发编程
- `11_process.py` - 多进程编程
- `12_concurrency.py` - 并发编程（多线程）
- `13_async.py` - 异步编程

### 5. IO 操作
- `14_io_operations.py` - 文件与 IO 操作

### 6. HTTP 与 Web
- `15_http_client.py` - HTTP 客户端
- `16_http_server.py` - HTTP 服务器
- `17_fastapi_demo/` - FastAPI 实战项目

## 🚀 快速开始

### 环境要求
```bash
Python 3.8+
```

### 安装依赖
```bash
pip install -r requirements.txt
```

### 运行示例
每个 Python 文件都可以独立运行：
```bash
python 01_syntax.py
python 02_basic_types.py
# ... 等等
```

### FastAPI 项目运行
```bash
cd 17_fastapi_demo
uvicorn main:app --reload
```

## 📖 学习建议

1. **按顺序学习**：建议按照文件编号顺序学习，从基础到高级
2. **动手实践**：每个示例都包含可运行的代码，建议边学边练
3. **修改实验**：尝试修改代码参数，观察不同的结果
4. **查看注释**：代码中包含详细的中文注释，解释关键概念

## 🎯 学习目标

完成本教程后，你将能够：
- ✅ 掌握 Python 核心语法和数据结构
- ✅ 理解面向对象编程思想
- ✅ 熟练使用 Python 标准库
- ✅ 编写异步和并发程序
- ✅ 开发 Web API 应用
- ✅ 处理文件和网络 IO
- ✅ 应用正则表达式和错误处理
